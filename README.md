Slipnet Collector is a desktop application that gathers Slipnet configuration files and displays them in a clean, customizable panel. You do not need any technical skills to use it. Just download, run, and collect.

## ✨ What This App Does

This tool helps you collect and manage Slipnet VPN configuration files. It shows all available configs in a simple window. You can sort, filter, and copy configs with one click.

The panel is customizable. You can change colors, layout, and display options to fit your preferences.

## 🎮 How to Use

When the app opens, you see:

- **Config List** – Shows all collected Slipnet configs.
- **Search Bar** – Type to filter configs.
- **Filter Buttons** – Sort by region, protocol, or speed.
- **Copy Button** – Click to copy a config to your clipboard.
- **Settings Panel** – Click the gear icon to customize.

## 🔧 Troubleshooting

**App does not open**

- Make sure your antivirus is not blocking the file. Add an exception for `slipnet-collector.exe`.
- Right-click the file and select "Run as administrator".

**No configs appear**

- Check your internet connection.
- Click the Refresh button.
- Wait 10 seconds for configs to load.

**Security warning**

This app is safe. The code is open source. You can inspect it on GitHub. Windows may flag it because it is not a signed app from a store.
